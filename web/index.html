Dotwise

One per row. One per column. One per colour.

Level 1 ★ 0
How to play
Place one dot in every row, column and coloured region. Dots can never touch — not even diagonally.
Tap a square to cycle empty → ✕ → dot. Drag to mark ✕ quickly. A wrong dot costs a heart. Finish with more hearts for more stars.
